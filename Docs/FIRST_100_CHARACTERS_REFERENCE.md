## Audio Pronunciation Guide

### Pinyin Tone Marks
- **First tone (¯)**: High and flat → mā
- **Second tone (´)**: Rising → má
- **Third tone (ˇ)**: Fall then rise → mǎ
- **Fourth tone (`)**: Sharp falling → mà
- **Neutral tone**: No mark → ma

## Code Point Reference

### Format
Each character is stored with its Unicode codepoint in hexadecimal:

```swift
(0x4E00, "一", ["yī", "jat1"], ["one"])
//  ↑     ↑      ↑       ↑        ↑
// code  char  pinyin  jyutping  meaning
```

## Next Steps for Audio

### Option 1: Use Built-in iOS TTS
```swift
import AVFoundation

let synthesizer = AVSpeechSynthesizer()
let utterance = AVSpeechUtterance(string: "hǎo")
utterance.voice = AVSpeechSynthesisVoice(language: "zh-CN")
utterance.rate = 0.4 // Slower for learners
synthesizer.speak(utterance)
```

### Option 2: Record Native Audio
Create MP3 files for each character:
- File naming: `U+04E00.mp3` (一), `U+04E8C.mp3` (二)
- Store in: `Resources/audio/hanzi/`
- Quality: 44.1kHz, mono, 64kbps
